# Hex Colour Guesser

A small browser game where the objective is to guess a target hex colour within 5 guesses. You get feedback on each hex digit in the form of arrow emojis telling you whether the target digit is higher or lower than your guess. Double arrows mean you are 3 or more away, checkmark means correct.

## A note on this project

This is an old project (around the end of 2025) that I wanted to dust off and put here. I knew much less about JavaScript and coding in general at the time, so the code is a bit scraggly. The original scope was larger: decimal input, level select and named colours. I lost motivation when I had a functioning version and didn't share it. I've removed the half-finished parts for this upload, but left it mostly as it was.

## Running it

Open `index.html` in a browser. No build step or dependencies.
